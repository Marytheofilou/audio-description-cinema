# Audio Description in Cinema 🎬

## About the Project

**Audio Description in Cinema: A Comparative Study**

This project presents my MA thesis in Arts in Translation, completed at
Hellenic American College Athens in June 2024.

The study focuses on audio description in cinema and its role in making
audiovisual content more accessible.
