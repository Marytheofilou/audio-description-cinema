Audio Description in Cinema: A Comparative Study

Abstract

Audio description is a live commentary which unfolds around the soundtrack, exploiting pauses to explain on-screen action, describe characters, locations, costumes, body language and facial expressions that aims to help people with visual impairments enjoy and understand better the film. In the present thesis, the method of audio description will be explored though a comparative analysis of one silent film and one with sound. The films are "Nosferatu: A Symphony of Horror and" "Carnival of souls".
